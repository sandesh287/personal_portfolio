Real-time Object Detection

YOLOv8 fine-tuning on custom urban surveillance dataset for autonomous navigation safety.

sticky_note_2 EXPERIMENT NOTES

Objectives

  • Reduce latency to <20ms for edge devices
  • Improve recall on small object classes (pedestrians)
  • Test quantization robustness

Methodology

Utilizing a pre-trained YOLOv8 backbone with an added feature pyramid network (FPN) layer. Hyperparameter search conducted via Bayesian Optimization.
