import torch.nn as nn

class VisualizerLayer(nn.Module):
    def __init__(self, in_features, out_features):
        super(VisualizerLayer, self).__init__()
        self.linear = nn.Linear(in_features, out_features)
        # Custom hook for real-time activation capture
        self.register_forward_hook(self.capture_activations)

    def capture_activations(self, module, input, output):

        return torch.relu(self.linear(x))

Challenges & Solutions

warning

The Bottleneck

Initially, transmitting large weight matrices over WebSockets caused significant UI lag and slowed down the training process on the backend.

lightbulb

The Optimization

Implemented a binary Protocol Buffers serialization layer and a dynamic sampling algorithm that only sends delta changes for inactive nodes.
